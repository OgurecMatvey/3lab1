# Анализ курса рубля (Командный проект)

Проект представляет собой приложение с графическим интерфейсом (UI) для анализа и прогнозирования курсов валют. 

## Распределение задач в команде:
* **Участник 1 (Аккаунт 1):** Проектирование архитектуры данных, реализация паттернов проектирования для источников данных (CSV, Excel). Разработка математической логики: расчет максимумов/минимумов и алгоритм экстраполяции по скользящей средней.
* **Участник 2 (Аккаунт 2):** Проектирование UI-набросков. Разработка графического интерфейса на базе Tkinter, интеграция интерактивных графиков matplotlib, вывод табличных данных и связь Frontend-части с Backend-частью.

## Особенности проекта:
* **Единый интерфейс:** Приложение выполняет обе задачи (прогноз и статистика) в рамках одного окна.
* Среда разработки: Python 3.
* Зависимости описаны в файле `requirements.txt`. Точка входа в приложение: `main.py`.

## Работа с Git:
Работа велась строго по веткам (`feature-backend` и `feature-frontend`). Все изменения сливались в ветку `dev` через Pull Requests с проведением перекрестного Code Review участниками команды, после чего релиз был отправлен в `main`.
